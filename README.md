# Budgy — Personal Finance App (V11.2 visual update)

This project preserves the existing V11.1 React + Vite app and its current finance functionality, with a visual pass based on the approved Budgy references.

## Included changes
- Repaired the Budgy wordmark styling so the `y` remains inline and blue instead of wrapping in the header.
- Updated the Inicio dashboard spacing, typography, neutral healthy-budget card, shortcut grid, and budget/recent-movement cards.
- Improved the visual hierarchy of Movimientos and Presupuesto with a consistent white/blue fintech style and more readable typography.
- Kept robot images as transparent image elements, centered within their layout containers.
- Added a persistent robot preference to onboarding and Settings. The chosen classic/alternative robot is reused on Inicio, budget analysis details, the welcome/splash screen and login/register views where applicable.
- Added the wordmark as text with the approved navy/blue treatment, rather than rasterizing the logo or using alt text as visible branding.

## Run locally
1. Extract the ZIP.
2. Run `npm install`.
3. Run `npm run dev`.

The project uses React 18, TypeScript and Vite.
